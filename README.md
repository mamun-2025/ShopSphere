
# 🚀 ShopSphere — Professional E-commerce Backend

A production-oriented **Django E-commerce Backend** project built step by step while learning modern backend development. The goal of this project is to master Django by developing a complete e-commerce backend from project setup to deployment.

---

# 🎯 Project Goal

Build a professional Django backend that includes:

* Authentication
* Product Management
* Inventory
* Shopping Cart
* Wishlist
* Coupons
* Orders
* Reviews
* REST API
* JWT Authentication
* PostgreSQL
* Docker
* Redis
* Celery
* Production Deployment
