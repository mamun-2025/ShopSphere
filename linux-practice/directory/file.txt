### File নাকি Directory — কীভাবে বুঝব?
এখানে ls -l কাজে আসবে।
ls -l

ধরো:
drwxr-xr-x ... notes
-rw-r--r-- ... README.txt

প্রথম character দেখো।
d
d

মানে:
Directory

-
-

মানে সাধারণ file।

তাই:
drwxr-xr-x

→ Directory

এবং:
-rw-r--r--

→ File

Permissions আমরা পরে বিস্তারিত শিখব।
